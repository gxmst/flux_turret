# Asset Generation Tools

This directory contains one-off or repeatable asset generation scripts for gxFlux.

## `generate_red_alert_asset_pass.py`

Generates the Red Alert style art pass for:

- Prism Tower GeckoLib model and block/item textures
- Tesla Coil GeckoLib model and block/item textures
- Psychic Beacon GeckoLib model, animation, and block/item textures

The script overwrites files under `src/main/resources/assets/flux_turret`, so run it only when intentionally regenerating those assets.
