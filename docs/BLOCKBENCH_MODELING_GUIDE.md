# Blockbench 建模指导 - 红色警戒风格炮塔

**目标受众**: Gemini AI / 人类建模师  
**工具**: Blockbench (GeckoLib 插件)  
**风格**: Command & Conquer: Red Alert 2 (红色警戒2)  
**日期**: 2026-06-09

---

## 📋 总体设计原则

### 红警风格核心特点

1. **硬朗的几何形状**
   - 避免圆形，使用八边形/六边形代替
   - 大量使用 45° 斜角装甲板
   - 直线多于曲线

2. **重工业美学**
   - 厚实的装甲感
   - 可见的机械结构（液压杆、支撑杆）
   - 铆钉、螺栓细节

3. **两大阵营风格**
   - **盟军**: 蓝色发光、流线型但不圆润、白色+灰色
   - **苏联**: 暗红色、更厚重、更多装甲板

4. **色彩对比**
   - 明暗对比强烈（深灰色底座 + 浅灰色装甲）
   - 警告标识（黄黑条纹）
   - 发光部分要明显

## 🎯 当前模型问题分析

### 问题 1: Prism Tower 过于复杂
- **当前**: 27KB，约 15-20 个骨骼
- **问题**: 细节过多，不够简洁
- **目标**: 简化到 15KB 以下，保留核心形状

### 问题 2: Tesla Coil 圆环太圆润
- **当前**: 4 个同心圆环
- **问题**: 红警风格不用完美圆形
- **目标**: 改为八边形环 + 金属支撑杆

### 问题 3: 缺少斜角装甲
- **当前**: 大多数底座是直角方块
- **问题**: 缺少红警特有的 45° 装甲板
- **目标**: 所有底座添加斜角过渡

### 问题 4: Grand Cannon 纹理过大
- **当前**: 31KB 纹理文件
- **问题**: 文件太大，可能细节冗余
- **目标**: 优化到 15KB 以内

## 🔧 具体建模指导

### 1. Tesla Coil (特斯拉线圈) - 优先级 ★★★★★

#### 当前问题
- 圆形环太圆润，不符合红警风格
- 中心柱是圆柱，应该更有棱角
- 缺少金属支撑结构

#### 改进方案

**底座 (Base)**:
```
尺寸: 16x4x16 (保持不变)
改进: 添加 4 个角落的斜角装甲
- 在四角添加 4x4x4 的斜切方块
- 使用 rotation 属性旋转 45°
```

**中心柱 (Center Pillar)**:
```
当前: 圆柱 4x28x4
改为: 六边形柱
实现方法:
1. 删除当前的圆柱
2. 创建中心方块: 3x28x3
3. 在六个方向各添加 1x28x0.5 的薄板
4. 形成六边形轮廓
```

**能量环 (Energy Rings)** - 核心改进:
```
当前: 4 个圆环 (ring_0 到 ring_3)
改为: 4 个八边形环

八边形环构建方法:
1. 不要使用圆形，使用 8 个方块拼接
2. 每个方块: 2x1x6 (宽x高x长)
3. 围绕中心旋转摆放: 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°
4. 形成八边形

尺寸递减:
- ring_0 (底部): 半径 6 像素
- ring_1: 半径 5.5 像素  
- ring_2: 半径 5 像素
- ring_3 (顶部): 半径 4.5 像素
```

**支撑杆 (Support Rods)** - 新增:
```
添加 4 根金属支撑杆连接环和中心柱

位置: 东西南北四个方向
尺寸: 0.5x20x0.5 (很细的杆)
起点: 中心柱外侧 (y=14)
终点: ring_0 内侧

作用: 增加机械感和结构感
```

**顶部节点 (Top Node)**:
```
当前: 6x6x6 方块
改为: 带金属框架的能量球

结构:
1. 中心球体: 保持 6x6x6
2. 添加 4 个金属支架 (上下左右)
3. 支架尺寸: 1x4x1
4. 从球体中心向外延伸
```

#### 纹理改进
```
当前尺寸: 128x128 (保持)
优化建议:
- 增加金属质感 (深灰 + 高光)
- 环上添加发光带 (蓝色或青色)
- 中心柱添加警告条纹 (黄黑)
- 螺栓细节在支撑点
```

#### 动画建议
```
idle 动画:
- 环缓慢旋转 (每个环不同速度)
- ring_0: 顺时针 2 秒/圈
- ring_1: 逆时针 2.5 秒/圈
- ring_2: 顺时针 3 秒/圈
- ring_3: 逆时针 3.5 秒/圈
- 顶部节点轻微呼吸 (scale 0.95 ↔ 1.0)

active 动画:
- 环加速旋转 (速度 x2)
- 顶部节点发光增强
- 中心柱轻微震动
```

### 2. Prism Tower (光棱塔) - 优先级 ★★★★☆

#### 当前问题
- 27KB 过于复杂
- 可能有过多装饰细节
- 需要简化到核心结构

#### 红警2原版设计
```
光棱塔的核心是:
1. 六边形底座
2. 三个棱镜支柱 (120° 分布)
3. 顶部聚焦器
4. 中心能量核心
```

#### 改进方案

**底座 (Base)** - 六边形:
```
不要使用圆形或方形，使用六边形

构建方法:
1. 中心六边形平台: 12x4x12
2. 使用 6 个梯形方块拼接六边形轮廓
3. 每个面添加装甲板细节

尺寸: 总直径约 14 像素
高度: 4 像素
```

**支柱层 (Mid Support)**:
```
三个棱镜支柱，120° 均匀分布

每个支柱:
- 底部: 2x8x2 (从底座向上)
- 中部: 棱镜晶体 3x4x3
- 顶部: 细杆 1x6x1 (连接到聚焦器)

位置:
- 支柱1: 0° (正前方)
- 支柱2: 120° (左后方)
- 支柱3: 240° (右后方)
```

**顶部聚焦器 (Top Focus)**:
```
核心能量聚焦装置

结构:
1. 中心球体: 4x4x4
2. 三个能量收集器 (对应三个支柱)
   - 尺寸: 2x1x2
   - 指向下方的三个支柱
3. 顶部发射口: 2x2x2
   - 向上延伸
   - 这是光束发射点
```

**简化原则**:
```
删除这些不必要的元素:
- 过多的装饰板
- 冗余的支撑结构
- 过细的细节 (小于 1 像素的)

保留核心元素:
- 六边形底座
- 三个棱镜支柱
- 顶部聚焦器
- 发光效果
```

#### 纹理优化
```
当前: 128x128
目标: 保持尺寸，优化内容

关键纹理:
1. 棱镜晶体 - 半透明，彩虹色边缘
2. 金属支架 - 白色/银色，高对比度
3. 发光部分 - 使用 glowmask 纹理
4. 底座 - 盟军白色装甲 + 蓝色线条
```

#### 动画建议
```
idle 动画:
- 三个棱镜轻微旋转 (各自独立)
- 顶部聚焦器呼吸效果
- 发光强度变化 (0.8 ↔ 1.0)

active 动画 (充能):
- 三个棱镜同时发光
- 能量从下往上流动
- 顶部聚焦器强烈发光
- 整体轻微震动

firing 动画:
- 顶部聚焦器猛烈闪光
- 支柱瞬间变暗 (能量释放)
- 快速回复到充能状态
```

## 🎨 通用纹理制作指南

### 红警风格纹理特点

**1. 高对比度**
```
不要使用柔和渐变
要使用硬边过渡

示例色阶:
- 暗部: RGB(30, 30, 35)
- 中间: RGB(80, 85, 90)
- 亮部: RGB(180, 185, 190)
- 高光: RGB(240, 245, 250)

不要: 平滑渐变 (50, 60, 70, 80...)
要: 跳跃性渐变 (30, 80, 180, 240)
```

**2. 金属质感**
```
金属表面要有明显的:
1. 高光条纹 (模拟反射)
2. 划痕和磨损
3. 铆钉和焊缝

技巧:
- 高光不要太多，集中在边缘
- 划痕要有方向性
- 铆钉用小亮点表示
```

**3. 警告标识**
```
红警建筑必备元素:

黄黑警告条纹:
- 宽度: 2-3 像素交替
- 角度: 45° 斜纹
- 位置: 底座边缘、活动部件

编号和文字:
- "01", "02" 等编号
- "DANGER", "AMMO" 等标识
- 字体: 粗体、全大写
```

**4. 发光纹理 (Glowmask)**
```
使用单独的 _glowing.png 文件

发光部分:
- 能量核心: 青蓝色 (#00FFFF)
- 充能线路: 蓝色 (#0080FF)
- 警告灯: 红色 (#FF0000)

技巧:
- 发光要明亮 (RGB > 200)
- 周围要完全透明
- 不要过度使用
```

**5. 细节密度**
```
Minecraft 风格要求:
- 不要过度细节化
- 每 4x4 像素区域有 1-2 个细节点
- 保持整体可读性

避免:
❌ 1像素的复杂图案
❌ 照片级真实纹理
❌ 过多颜色 (>8 种主色)

追求:
✅ 清晰的大色块
✅ 明显的边缘
✅ 风格化而非写实
```

## 📐 Blockbench 操作技巧

### 创建八边形/六边形

**方法 1: 手动拼接**
```
1. 计算每个面的角度
   八边形: 360° / 8 = 45° 间隔
   六边形: 360° / 6 = 60° 间隔

2. 创建方块 (代表一个面)
3. 设置 pivot point 到中心
4. 旋转: 0°, 45°, 90°, 135°...
5. 复制并旋转剩余的面
```

**方法 2: 使用插件**
```
如果 Blockbench 有 "Create Polygon" 插件:
1. 选择多边形类型
2. 输入边数
3. 输入半径
4. 自动生成
```

### 斜角装甲制作

```
45° 斜角技巧:

1. 创建方块: 4x4x4
2. 设置 rotation: [0, 45, 0]
3. 位置: 放在底座四角

或使用 UV 映射:
1. 创建梯形方块
2. 手动调整 UV 坐标
3. 让纹理看起来是斜的
```

### 动画关键帧设置

```
基本原则:
- 少而精，不要过多关键帧
- 使用 easing 让运动平滑

示例 (旋转动画):
关键帧 0.0s: rotation [0, 0, 0]
关键帧 1.0s: rotation [0, 360, 0]
Easing: linear

循环设置:
Animation → Loop Mode → Loop
```

body - 主体 (可旋转)
barrel - 枪管 (可旋转/移动)
effect - 特效部件 (发光、旋转)
```

### 动画标准
```
idle - 待机动画 (循环)
active - 激活/充能 (循环)
firing - 开火 (单次播放)
cooldown - 冷却 (单次播放)
